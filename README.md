This is a practice project as part of the continuing education program at the “Developer Akademie.”

In this project, we’ll use HTML, CSS, and JavaScript to build an ordering platform with an interactive menu, a shopping cart, and a test order.

On this website you can pick your favourite dishes, add them to the basket or remove them if you change your mind and then order it.

This website is fully responsive os that you can use it on any device.

This is a purely front-end project with no back-end integration. 

LocalStorage is used to save the shopping cart from the last session so it’s still there when the user returns to the site.
